🛒 Gadzo – Full Stack MERN E-Commerce Platform

Gadzo is a production-ready full-stack e-commerce application built using the MERN stack. The platform includes separate deployments for users, admin, and backend API with secure authentication and online payment integration.

🚀 Live Demo

🌐 Frontend: https://gadzo-frontend-git-main-ayshas-projects-1b6c8c58.vercel.app/

🛠 Admin Panel: https://gadzo-admin.vercel.app/

🔗 Backend API: https://gadzo-backend.vercel.app/

🧰 Tech Stack

Frontend: React.js

Backend: Node.js, Express.js

Database: MongoDB (Mongoose)

Authentication: JWT

Payment Gateway: Stripe

Image Upload: Multer + Cloudinary

Deployment: Vercel

✨ Features
👤 User Features

User registration & login (JWT authentication)

Product browsing with filtering and search

Add to cart functionality

Secure Stripe checkout

Order history tracking

🛠 Admin Features

Add / Update / Delete products

Upload product images (Cloudinary integration)

View all orders

Update order status

🔐 Security

JWT-based authentication middleware

Password hashing using bcrypt

Role-based access control

Environment variable protection

📦 Project Architecture

Separate frontend, backend, and admin deployments

RESTful API design

Cloud-based image storage

Scalable modular folder structure
